# XXD Panel 003 · 公共议题观念线条生成核心

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、线条路线、象征、议题和文案。


## 0. 不可改变的美学动机

每个变化画框必须呈现这条链：

**当前照片中特定且可辨认的主体或不可拆分关系 → 提炼真实的方向、连接、矛盾、压力与转机 → 压缩为一组连贯的黑色手绘线条 → 线从画面边缘进入，在偏下、偏侧或靠边处盘绕、交错、回折与收紧 → 随内在力量向上或向外抬升并释放 → 与原主体有关的象征轮廓从运动中自然显露，但不完整封闭、不直接解释 → 冷白、米白或低饱和浅色底与大面积留白 → 文字只是线条系统里的微小痕迹。**

线可以让人联想到被拉紧的细铁丝、路径、束缚或伤口，但不能字面画成金属物件、地图、牢笼或人体创伤。意义来自源图真实的受力与关系，不来自通用拳头、眼泪、心形、鸟笼、铁链、红丝带、标语或抗议图标。

## 1. 锁定源图事实

在内部判断但不输出分析：

1. 找出一个主要主体或确实不可拆分的核心关系。
2. 锁定至少三个源图专属线索：轮廓、姿态／朝向、开口、连接、遮挡、负形、关系距离或主导方向。
3. 分别判断源图真实的方向、连接、矛盾、压力与转机；没有证据的项保持空缺，不能硬编。
4. 确定线条从哪一侧边缘进入，在哪个偏下／偏侧位置盘绕与收紧，又向哪个上方／外侧方向释放。
5. 确定一个能在运动中浮现的源图专属象征轮廓；它应一眼可感知原物，但不需要完整闭合。
6. 只在真实受力、交叉或方向改变处标记允许出现的尖刺、结点、倒钩或短横。
7. 选择冷白、米白或一款尊重源图气氛的低饱和浅色底。

不得虚构人物经历、地点、事件、情绪、伤害、责任、政治立场、公共议题或倡议。文字只能使用用户提供或画面事实支持的含义。

## 2. 连续黑线系统

- 使用一条或少量彼此属于同一系统的黑色／近黑手绘线，不机械描摹照片外轮廓。
- 线条以细为主，粗细轻微变化，保留墨线摩擦、迟疑、断裂、重新接续和压力感。
- 线路必须有因果：进入、盘绕、交错、回折、收紧、穿越、抬升、释放。每个转折都对应源图事实。
- 主体轮廓从线路的负形、交叉和方向变化中显露，不画成完整图标、闭合徽章或说明图。
- 不使用光滑贝塞尔曲线、统一描边、霓虹线、金属丝 3D、投影、发光或写实体积。

## 3. 力点而非装饰

- 尖刺、结点、倒钩、短横只出现在真正的受力点、交叉点或方向改变处。
- 每一种力点符号都必须有结构作用：阻挡、收紧、固定、摩擦、断裂或转向。
- 同一种符号不要均匀重复；不得把整条线做成铁丝网、藤蔓、装饰花纹或纹身。
- 不添加无关的人脸、手、鸟、笼、锁、泪滴、红十字、感叹号、地图、旗帜或标语。

## 4. 构图与留白

- 底色为冷白、米白或低饱和浅色，大面积留白是“沉默”和张力，不是等待填满的空区。
- 活跃线条系统偏下、偏侧或靠近边缘，不居中、不铺满、不做对称 Logo。
- 阅读路径通常从边缘进入，在低位受困，再向上或向外释放；具体方向必须服从源图。
- 画面安静而紧张、极简但不轻松。删除背景、写实光影、复杂场景和无意义的视觉丰富。
- 默认只用黑色／近黑线。用户明确要求色彩时，最多允许一个极淡的源图浅色底或一个极小且有证据的标记。

## 5. 003 专属文字

文字是**线条系统里的微小痕迹**，不直接解释画面，不成为口号或视觉中心。

- 自动文案从源图可证实的关系、压力、穿越、转机或释放中提炼一个极短主题词或短句，不替用户建立议题立场。
- 默认一条极短文字；只有用户提供或证据可靠时，才增加一个更小的编号、地点或注释。
- 字形纤细、克制、略带手工吸墨感，保持目标语言的自然结构、标点、间距与阅读方向。
- 放在大面积空白中，靠近一个转折、交叉、受力点或释放点，但不能压在线上或遮住识别轮廓。
- 禁止大标题、粗体口号、解释段落、数据墙、伪外语、装饰字母和随意编号。
- 用户最终成稿逐字保留；无字模式不得出现字母、文字、数字或伪文字。

## 6. 当前模式与壁纸

调用方会在本提示词后附上唯一当前模式、准确尺寸、源图可见性和锁定文字。只执行附加块中的当前值。

- 纯设计版和壁纸不显示源照片、分界线或摄影预留区。
- 每张壁纸按目标宽高比重新安排进入边、低位受力区、释放方向和系统 UI 安全区；不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸中，原照片锁定内容与受力事实；定调图只锁定线性语法、摩擦感、稀疏度、张力尺度、浅色底和微型文字。不得裁切或顺序垫图。

## 7. 生成前检查

1. 至少三个源图专属线索仍能让主体或关系被感知。
2. 方向、连接、矛盾、压力和转机都有源图依据，没有虚构议题。
3. 黑线从边缘进入，在低位或侧位盘绕／交错／回折／收紧，再向上或向外释放。
4. 象征轮廓从线的运动与负形中显露，不是完整图标或机械描边。
5. 线有摩擦、迟疑、断裂与压力变化；所有尖刺、结点、倒钩和短横都位于真实力点。
6. 冷白、米白或低饱和浅底占主导，留白充足，没有多色填充、复杂场景、写实光影、3D 或装饰曲线。
7. 文字准确、极少、符合目标语言且严格从属于线条；无字模式完全无文字。
8. 当前模式、尺寸、源图可见性、壁纸安全区和文案设置服从附加块。
9. 没有拼贴总览、Logo、水印、UI、样机、第二焦点或无关象征。
